## 三、本轮迭代目标

本轮目标是修复最影响体验的 Bug，补齐受击反馈，为演示视频录制打基础。


### P0-1：Boss 受击反馈

**现状**：受击音效已接入，但身体无任何反应，视觉上像打木桩。

目前没找到合适的 Boss 受击/眩晕 Montage 素材，所以先不做身体僵直。改用三种无动画的反馈方案：

1. **短减速**：受击瞬间用 GE 减速 30-40%，持续约 0.1-0.15s
2. **闪白**：命中瞬间对 Boss 材质做一次 Emissive 脉冲（约 0.1s）
3. **受击火花**：用 Niagara 做 Hit Spark，放在命中点

三种叠加后，即使没有身体后仰动画，受击感知也能明显提升。

> 注意：短减速与 Boss 技能释放状态要保持互不干扰，避免减速影响行为树决策或技能执行流程。


### P0-2：Boss 血条缓动

血条瞬间跳变太硬，改成双层：

- 前层（红）：伤害瞬间扣减
- 后层（黄白）：延迟 0.3s 后平滑插值追平

在 UMG 里用双层 ProgressBar 实现，Tick 里做 FInterp 追赶。


### Bug 1 / T1：Boss 技能决策锁

**问题**：Boss 放技能放到一半，Player 一换距离就中断换成另一个，体验很差。

**方案**：Boss 进入技能执行阶段后锁定当前技能，距离变化只影响下一次技能选择，不打断当前执行。

两种实现方式：

**方式一（行为树层）**：
- Blackboard 增加 `IsSkillLocked` 布尔键
- 技能 Task 开始时置 True，结束时置 False
- 距离判断节点上，`IsSkillLocked == True` 时跳过重新评估

**方式二（GAS 层）**：
- 技能 GA 激活时挂载 `Boss.Skill.Executing` Tag
- 行为树距离分支排除该 Tag
- 技能结束时清除

先试方式一，如果行为树层改动太麻烦就换方式二。

**预期效果**：Boss 完成当前技能后，再根据新距离选择下一个技能。


### Bug 4：打包分辨率异常

打包后分辨率跟编辑器不一致，排查顺序：

1. Project Settings 里的默认分辨率设置
2. 打包目录下的 GameUserSettings.ini
3. 是否有自定义分辨率逻辑覆盖


### Bug 2：完美闪避判定异常

二阶段球技能下，离很远也能触发完美闪避。

先加 Debug 输出，确认触发时距离、伤害判定范围、完美闪避检测窗口的实际数值。排查球技能的碰撞检测是否在不该命中的情况下返回了 Hit。


### Bug 3 / T2：胜利 Tag 异常挂载

战斗中偶发挂载胜利 Tag。

先建立 Tag 清单与生命周期记录，定位异常挂载的实际触发路径。如果定位不到也顺延到 9 月。


### P1-1：Niagara 粒子（受击火花）

优先级最高的是受击火花，Player 攻击命中 Boss 时在命中点生成。Dash 烟尘和 Q 技能地面冲击波可以往后放。
