# RPGBattlePrototype V1.1 开发日志

> UE5 战斗原型 · V1.0 完结后的持续迭代与优化记录

---

## Day 1（2026.08.17）

### 今日完成

#### 1. Boss距离区间切换逻辑优化

- 修复 Boss 在判断 Player 距离时，距离恰好处于区间切换临界值附近，会中断当前技能并切换至其它距离区间技能的问题。
- 通过 Tag 层 + 行为树层双重阻断对技能切换进行限制。
- 优化后该问题出现频率已明显降低。

#### 2. 完美闪避逻辑重构

- 重新梳理并重写完美闪避判定逻辑。
- 新增独立的闪避窗口 Anim Notify State（ANS），用于明确控制完美闪避的有效时间窗口。
- 结合 Player 与 Boss 的距离及时间条件进行判定。
- 目前除三个近战技能外，其余 Boss 技能均已能够正常触发完美闪避。
- 三个近战技能的判定仍存在异常，后续继续排查。

#### 3. Boss变球技能与闪避逻辑联动修复

- 优化 Boss 变球技能的表现问题。
- 随着完美闪避逻辑重新调整，同时解决了 Dash 处于 Cooldown 时，按下 Dash 键虽然没有实际位移，却仍能获得完美闪避收益的问题。
- 目前 Dash 的实际执行状态与完美闪避奖励判定基本保持一致。

### 今日思考

今天主要集中处理 Boss 距离切换与完美闪避相关问题，实际开发时间较长。

完美闪避在重新梳理后已经能够覆盖绝大多数 Boss 技能，但三个近战技能的判定仍然存在问题。虽然已经重新设计了独立的闪避窗口与距离、时间判定流程，但目前仍需要进一步确认近战技能在动画、碰撞与判定时序上的差异。

与此同时，完美闪避逻辑的重构也顺带解决了 Dash Cooldown 状态下仍能获得完美闪避收益的问题，使技能实际执行状态与战斗奖励判定之间的关系更加合理。

目前主要剩余问题集中在少数 Boss 近战技能的完美闪避判定，以及部分行为树距离切换的边界情况。后续暂且将继续以稳定现有战斗逻辑、减少异常情况为主，而不是继续大幅增加新功能。

> **开发耗时**：约 6 h

## Day 2（2026.08.18）

### 今日完成

#### 1. 完美闪避逻辑修复

- 测试确认 Boss 攻击造成伤害的瞬间进行 Dash，可以正常触发完美闪避。
- 目前完美闪避核心判定基本修复。

#### 2. Boss 转阶段与二阶段逻辑优化

- 修复 Boss 转阶段结束并释放变球技能后无法再次释放的问题。
- 优化二阶段根据距离判断释放变球技能的逻辑。
- 转阶段动画播放期间的滑步问题暂未解决，作为已知 Bug 保留。

#### 3. Player 状态 Bug 修复

- 修复 Dash 后异常赋予 Player 其它 Tag 的问题，解决因此导致 Player 无法进行攻击的异常。

#### 4. UI 优化

- 优化 UI 整体布局。
- 修复打包发行版后 UI 显示错位的问题。

### 今日思考

今天主要是在继续清理 V1.0 遗留下来的战斗 Bug。随着这些问题逐个解决，也开始感觉到 V1.1 和之前单纯开发功能时的区别：现在更多是在验证和修正各个系统之间的实际交互，而不是单独实现某一个功能。

部分问题在重新梳理逻辑后能够比较明确地定位并解决，但也有一些问题仍然需要继续观察和测试。当前 Boss 转阶段动画中的滑步问题暂未解决，因此暂时保留，避免为了处理单个表现问题而影响已经稳定的战斗逻辑。

整体来看，V1.1 目前仍以修复遗留问题、稳定战斗体验为主要目标。随着 NEXT_STEPS 中的问题逐步收尾，后续可以将更多精力转向实际试玩体验和表现效果的进一步完善。

> **开发耗时**：约 4 h
